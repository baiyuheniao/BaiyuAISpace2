# BaiyuAISpace2 分层记忆

根据用户提供的《Claude Code 的 7 层记忆系统》笔记实现的应用原生记忆能力。该笔记作为产品设计输入，不作为 Claude Code 内部源码或行为的验证依据。面向研究、写作、规划、开发等 Agent 场景，不自动扫描 Git、配置文件或 `.env`。

## 使用入口

打开「模型工具 → 分层记忆 → 管理记忆与设置」。原先的 `@modelcontextprotocol/server-memory` 推荐预设由此入口替代。已有外部 MCP 配置和其数据保留，不自动删除或导入；仍启用的旧服务由用户自行停用，避免两套记忆同时工作。

默认启用会话线索采集、相关记忆注入和自动摘要。后台整理默认关闭，向量模型默认不选择。记忆有独立总开关，不依赖 Chat 的 MCP 总开关；关闭后停止采集、检索和记忆工具。设置存储在后端，保存后立即生效并跨重启保留。

## 七层的对应实现

| 层 | 本应用实现 |
| --- | --- |
| 会话上下文 | Chat 每次请求提供当前日期、会话、工作目录及文件权限；原系统提示词、Skill、RAG 流程继续生效。成功保存的用户/助手消息产生脱敏记忆副本。Agent Team 保存自己的输出及收到的会话线索。助手输出标记为待核实。 |
| 自动压缩 | 文本 token 保守估算达到预算的 80% 且超过 8 条消息时，用当前模型生成摘要，保留最近至少 6 条消息并对齐用户消息边界。重复只读工具结果引用最近的相同结果；大结果继续使用原有有界压缩。手动压缩入口保留。 |
| 持久存储 | 用户、工作空间、会话分别存储作用域及 owner；使用 `memdir/memory.sqlite` 的事务保证条目、向量和审计一致。完整聊天/群聊继续保留在原数据库，活动摘要单独保存，不覆盖历史。支持导出和恢复记忆快照。 |
| 智能搜索 | 本地结巴中文分词 + BM25；可选择设置中已有的嵌入模型叠加余弦相似度；结果带来源、更新时间、确认状态和过时标记，新鲜度参与排序。 |
| 提示词注入 | 每次请求用最新问题检索，仅注入当前有权访问的相关记忆摘录。追加到原系统消息，兼容只读取第一条 system 的服务商。记忆明确标为历史数据，当前用户说明优先。 |
| 后台整理 | 显式启用并选择模型后，在无 Chat/Agent 推理活动至少 5 分钟时，每分钟检查一次新材料。一次仅处理一个会话的最近 12 条线索，输入有上限；无新材料不重复调用。输出待确认建议，不能执行工具。用户开始新请求或修改设置会取消正在运行的后台调用。 |
| 权限与隐私 | 工具不能指定其他工作空间/会话 owner；常见凭据行和私钥块在入库、向量调用前过滤。用户能编辑确认、遗忘，审计仅记录动作、ID 和时间。遗忘同时移除向量及关联的后台派生建议，采集 ID 墓碑阻止同一历史消息自动重新收录。 |

## 作用域

- `user`：跨所有场景共享，适用于稳定用户偏好；自动采集不会直接晋升为用户全局记忆。
- `workspace`：普通 Chat 使用规范化工作目录的摘要作为场景标识；没有工作目录时按 Chat 会话隔离。Agent Team 使用工作组 ID。两者不因相同目录而隐式共享。
- `session`：普通 Chat 使用会话 ID；Agent Team 使用 Agent ID，保证成员私人线索隔离。

模型工具为 `memory_search`、`memory_remember` 和 `memory_forget`。模型写入的记忆为未确认；管理界面编辑确认后才标为已确认。未确认的普通记忆可作为带标记的参考，后台建议则完全不参与普通自动注入，用户明确搜索后台建议或在界面确认后才可使用。

## 配置和成本

默认文本上下文预算为 24,000，注入预算为 2,000，过时提醒为 7 天。预算是可调的保守文本估算，不是模型的实际 tokenizer 计数，图片、视频以及服务商内部 token 开销无法精确计算。应按所选模型容量调整。

自动摘要会调用当前聊天/Agent 模型；向量化和后台整理分别调用用户选择的模型。凭据只按配置 ID 从系统 keyring 读取，嵌入配置使用现有 `emb_` 命名空间，设置中不存明文凭据。未配置向量模型时只执行本地检索；向量调用失败时回退关键词检索并记录状态日志。

向量缓存按模型配置签名及正文匹配，每次检索最多补建 32 条缺失向量，后续请求增量补齐。尚未完成向量化的记录仍参与全量关键词搜索。记忆注入为有预算的摘录，需要完整内容时使用 `memory_search` 或管理界面。后台置信度为模型自评，不是经校准的概率或实测结论。

## 存储与遗忘的边界

Windows 默认记忆路径为 `%APPDATA%/com.baiyu.aispace/memdir/memory.sqlite`。原消息和原活动摘要仍在原聊天数据库；Agent Team 活动摘要在记忆数据库的独立表中。遗忘记忆不会删除原始聊天、活动摘要或用户已导出的独立文件。

快照只包含记忆条目，不包含凭据、模型设置、向量缓存或原始聊天。恢复需用户在界面确认，仅补入缺失条目，不覆盖现有编辑；可恢复曾遗忘的条目，所有恢复条目重新标记为未确认。

凭据过滤是常见模式过滤，不保证识别所有个人隐私。敏感场景应关闭采集；后台建议始终与已确认事实区分。后台失败会记录日志，等待新材料后再尝试，不会每分钟反复消耗相同材料的调用费用。

## 验证

- `cargo test --quiet`：80 项通过，包含跨作用域隔离、持久化、凭据过滤、遗忘与派生建议/向量清理、中文检索、三类服务商系统提示词保留、自动摘要续接。
- 向量和后台整理用回环 HTTP 服务通过真实请求构造路径测试：只发送当前允许访问且已过滤的材料，后台建议不进入普通搜索，无新材料不重复整理。该测试不代表真实模型的摘要或语义检索质量评测。
- `pnpm build`：类型检查和前端打包通过。
- 真桌面验证：管理界面渲染、恢复测试条目、编辑确认、开关保存、重启持久化和遗忘通过。独立测试条目已清理。
- `pnpm tauri build`：普通安装包生成，但本机缺少更新包签名私钥；使用临时 `bundle.createUpdaterArtifacts=false` 覆盖配置验证普通安装包。仓库发布配置不变。
